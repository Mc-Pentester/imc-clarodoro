RÉCUPÉRATION DU COMPTE

Réinitialiser le mot de passe PDG

Utilisez le code de récupération configuré par l’administrateur du serveur. Cette opération ne supprime ni le compte ni les données de l’établissement.

Le code n’est pas votre ancien mot de passe.

Retour à la connexion PDG

Après la réinitialisation, retirez ou faites tourner le code de récupération dans la configuration du serveur.
